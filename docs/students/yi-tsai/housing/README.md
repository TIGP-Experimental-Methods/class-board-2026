# Project 3 housing: course hand-in

This folder is the **hand-in copy** of my housing, the files the course collects here (`housing.scad`, `base-shell.stl`, `hood.stl`, `coupon.stl`, `bottom-plate.dxf`, `housing.png`; `nmr-params.scad` is there because `housing.scad` includes it).

It is a snapshot, generated from [https://github.com/tojestspacja/nmr-instrument](https://github.com/tojestspacja/nmr-instrument) (`mechanical/`, commit `9bac152`) by `tools/handin.py`. **Do not edit it here**; change the design there and regenerate.

The whole project (housing, probe, B0 coils, simulator, data, fabrication files, and how the real instrument works) is at **https://tojestspacja.github.io/nmr-instrument/**.

Print orientation and parts: `housing.scad` with `part = "shell"`, `"hood"`, `"coupon"`, `"plate"` (DXF).
