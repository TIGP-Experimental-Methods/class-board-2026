## 我的決定

1. 不要通風孔，四面牆保持乾淨。
2. RESET/BOOT：拆 4 顆螺絲、把電路板拿出來按，不另外開洞。
3. 後牆：5 個接頭維持 4 個分開的開口，後牆比較堅固，從外面看不到盒子裡面。
4. 標示：頂蓋和後牆都用白色雙色嵌入字。後牆標接頭名稱和端子的 +/− 極性。我接受後牆多出來的換色時間和耗材。
5. 外型：直角，工具箱風格。
6. 我的名字 **TEE REN QIAN**，用白字放在低頂蓋左邊的空白處。

## Claude 的問題和我的回答（第 2 步）

Claude 先從電路板檔 `hardware/class-board.kicad_pcb` 讀出後牆五個接頭的腳位和絲印，再問。

1. **後牆的名字放哪裡？** DC 插座的開口從底一路開到接近牆頂，後牆上放不下它的名字。
   → **名字放頂蓋後緣**，每個接頭正上方一個。頂蓋面朝下印，白字幾乎不用換色。後牆只標極性。
2. **極性怎麼標？** J903 是 H 橋輸出，兩極輪流當正極，沒有固定的 +/−；J905 有三極。
   → **照電路板絲印**：J901（外部電源 7–18 V）標 + −；J903 標 1 2；J905 標 + C −（+VCOIL、COIL、GND）。
3. **頂蓋要不要維持兩片？** 兩個高度差 12.3 mm，一片的話一定要支撐。
   → **維持兩片**，都不用支撐。
4. **名字怎麼排？**
   → **一行，約 6 mm 高**。
