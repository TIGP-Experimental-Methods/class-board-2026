# Student gapped copies — what each section places back (brief §12, D6; v0.7 three sections)

Generated by `scripts/gen_student.py` from the released sheets in `sheets/`. Do not edit by hand.

The design is built complete, then 3–4 items are deleted per sheet (a decoupling pair, one repeated
channel, one connector — brief §12). **The reference designators are unchanged in the full design**, so a
student who re-places a part with the same reference gets the same footprint position back on *Update PCB
from schematic*. Wires, labels and power symbols of the deleted parts stay in place — the dangling ends
are the intended ERC findings.

## How the counts were taken

```
"C:\Program Files\KiCad\10.0\bin\kicad-cli.exe" sch erc --severity-all --format json \
      -o <out>.json  student/<sheet>_gapped.kicad_sch
```
ERC is run on the sheet **standalone** (not through the root schematic), so the baseline is high: every
hierarchical/global label that leaves the sheet reads as dangling, and every power input looks undriven.
Only the *difference* against the same sheet ungapped is meaningful, and that difference is the table above.

## PDFs

```
"C:\Program Files\KiCad\10.0\bin\kicad-cli.exe" sch export pdf -o docs\schematic-full.pdf class-board.kicad_sch
```
`kicad-cli` has no per-sheet option for a hierarchical design — `sch export pdf` always writes the whole
book. `docs/schematic-full.pdf` is therefore the single reference document; the page number in each table
above is the sheet's page in it. (Running `sch export pdf` on a file in `sheets/` does produce a one-page
PDF, but standalone — without the root sheet's page numbering and cross-references — so it is not used.)
